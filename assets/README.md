# App icons & splash screens

Drop two source images here, then run `npm run assets` (uses `@capacitor/assets`)
to generate every icon/splash size for iOS and Android automatically.

- `icon.png` — 1024×1024, no transparency, no rounded corners (the stores round it).
- `splash.png` — 2732×2732, important content centered within the middle ~1200×1200.

Suggested look: the app's deep slate (`#0d131b`) background with a simple mark
(a sun/snowflake or "HWD" monogram) centered.
